Como adicionar um caderno novo

1. Suba o arquivo .html nesta mesma pasta do GitHub.
2. Acrescente uma linha ao bloco CADERNOS, no topo do script deste arquivo:

{ materia:"manobrabilidade", badge:"Bloco E", titulo:"Nome do caderno",
  arquivo:"nome_do_arquivo.html", desc:"Resumo de uma linha.", tags:["BANCA"] },

Use materia entre: manobrabilidade · arte-naval (ou crie uma nova em MATERIAS). A estante se reorganiza sozinha.
