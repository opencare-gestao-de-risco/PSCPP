Como adicionar um caderno novo

1. Suba o arquivo .html nesta mesma pasta do GitHub.
2. No código deste index.html, acrescente uma linha ao bloco CADERNOS, no topo do script:

{ bloco:"E", titulo:"Nome do caderno", arquivo:"nome_do_arquivo.html",
  desc:"Resumo de uma linha.", tags:["BANCA","Nomoto"] },

Pronto — a estante se reorganiza sozinha. Sem banco de dados, sem configuração.
